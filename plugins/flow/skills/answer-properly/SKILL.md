# Explain Properly

For every explanation:

1. State the real-world outcome and problem the behavior serves.
2. Translate important values and states into their real-world meaning.
3. Identify the scenario that reaches this behavior.
4. State why it matters and what fails if it is wrong.
5. Place it in the relevant component and end-to-end flow.
6. Assume the reader has not read the source; names are evidence, not explanations.
7. Explain the system behavior, not merely the implementation syntax.

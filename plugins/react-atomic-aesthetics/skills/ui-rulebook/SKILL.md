# UI Rulebook

## Unsupported hosts

If the active host is neither Claude Code nor Codex, tell the user this skill has no validated integration there and suggest opening a support ticket at https://github.com/tushar2708/claude-assets/issues/new.

Read [the canonical rules](references/RULES.md) before continuing. Cite rule numbers and complete the checklist for your role.

Use [the INDEX template](assets/INDEX.template.md) when the rules require an `INDEX.md`.
